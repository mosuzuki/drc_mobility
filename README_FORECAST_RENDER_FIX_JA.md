# 予測グラフ表示修正パッチ（2026-10-23）

前回の `drc_mobility_n159_ml_forecast_patch.zip` を適用したリポジトリに、このパッチの中身をリポジトリ直下へ上書きしてください。

## 原因

- `assets/app.js` の `updateFinalSizeProjectionChart()` が途中で終わっており、描画に使う `Plotly.newPlot` が実行されていなかった。構文は正常なため従来の構文チェックでは検出されなかった。
- `updateMlForecastChart()` は、7日先の表示に1件の週別予測点しか存在せず、線状の予測区間が表示できなかった。

## 修正

- 最終規模予測：観測累積値＋最大260日間のシナリオ別累積中央値、50%・90%区間、推定終息日の有無、要約カードと説明を表示。
- 短期予測：7/14/21/28日のいずれでも予測中央値と90%区間を表示。7日の場合にも縦の予測区間を表示。
- `scripts/test_forecast_render.cjs` を追加し、短期4期間×利用可能モデル、最終規模4シナリオすべての描画データが作られることを確認。`update_dashboard_all.py` の自動検証に組み込み。
- `index.html` のJavaScriptキャッシュバスターを更新。

新しいモデルの再学習は行っていません。N159に基づく予測JSONは前回のパッチをそのまま使用します。今回の修正は描画および回帰検証のみです。

ローカル検証：Node.js描画テスト、Pythonの予測データ整合性検証、JavaScript構文テスト、Plotlyの部分ブラウザ描画テストを実施。実際のGitHub Pagesサイト上での画面検証は未実施です。
